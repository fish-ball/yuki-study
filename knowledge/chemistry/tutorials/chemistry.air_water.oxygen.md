# 氧气制取与性质

## 一句话记住
氧气“三分离、两助燃”，实验室常用过氧化氢或高锰酸钾制取，收集看密度与溶解性，性质实验重现象描述与安全细节。

## 核心概念
- **物理性质**：无色无味气体，密度略大于空气（可用向上排空气法），不易溶于水（可用排水法）。液态和固态呈淡蓝色。
- **化学性质**：化学性质较活泼，具氧化性与助燃性（本身不可燃）。
  - 碳：$\text{C} + \text{O}_2 \xrightarrow{\text{点燃}} \text{CO}_2$（白光，生成使澄清石灰水变浑浊的气体）
  - 硫：$\text{S} + \text{O}_2 \xrightarrow{\text{点燃}} \text{SO}_2$（蓝紫色火焰，刺激性气味，瓶底留水吸收）
  - 铁：$3\text{Fe} + 2\text{O}_2 \xrightarrow{\text{点燃}} \text{Fe}_3\text{O}_4$（火星四射，黑色固体，瓶底铺细沙或留水）
  - 磷：$4\text{P} + 5\text{O}_2 \xrightarrow{\text{点燃}} 2\text{P}_2\text{O}_5$（大量白烟，常用于空气成分测定）
- **实验室制取**：
  - 原理①（固液常温）：$2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2\uparrow$
  - 原理②（固体加热）：$2\text{KMnO}_4 \xrightarrow{\Delta} \text{K}_2\text{MnO}_4 + \text{MnO}_2 + \text{O}_2\uparrow$
  - 装置选择：发生装置由反应物状态与反应条件决定；收集装置由气体密度与溶解性决定。
  - 验满：带火星木条放瓶口（排空气法）；气泡从瓶口连续均匀冒出（排水法）。
  - 检验：带火星木条伸入瓶内，复燃即为氧气。

## 例题演示
【例1】某校实验考查要求用高锰酸钾制取氧气，请结合装置图回答：
（1）写出该反应的化学方程式：________________________。
（2）试管口塞一团棉花的目的是________________________。
（3）实验结束时应先________，后________，防止水倒吸引起试管炸裂。
【解析】
（1）$2\text{KMnO}_4 \xrightarrow{\Delta} \text{K}_2\text{MnO}_4 + \text{MnO}_2 + \text{O}_2\uparrow$
（2）防止加热时高锰酸钾粉末随气流进入导管，造成堵塞或污染水槽。
（3）将导管移出水面；熄灭酒精灯。（记忆口诀：“先撤管，后熄灯”）

【例2】下列关于氧气性质与用途的说法正确的是（ ）
A. 氧气能支持燃烧，可用作火箭燃料
B. 铁丝在氧气中剧烈燃烧，生成红棕色固体
C. 硫在氧气中燃烧比在空气中更旺，说明浓度越高反应越剧烈
D. 氧气化学性质活泼，常温下能与金、铂等金属反应
【解析】选C。A错，氧气助燃但不可燃；B错，生成黑色固体四氧化三铁；D错，金、铂化学性质极稳定，常温不与氧气反应。

## 易错点
- **催化剂概念混淆**：催化剂是“改变”反应速率（可加快也可减慢），反应前后“质量”和“化学性质”不变，物理性质可能改变；书写方程式时写在箭头上方，不列入反应物/生成物。
- **实验步骤颠倒**：加热固体制气遵循“查装定点收离熄”。若先熄灯后撤管，试管内压强骤降会导致水槽水倒吸炸裂试管。
- **现象描述不规范**：严禁将结论当现象。如“生成二氧化碳”“生成水”均为错误表述，应改为“生成使澄清石灰水变浑浊的气体”“瓶壁出现水雾”。注意“烟”（固体小颗粒）与“雾”（液体小液滴）的区别。
- **集气瓶预留液体目的不同**：硫燃烧留水是为了吸收有毒的$\text{SO}_2$防污染；铁燃烧留水或铺沙是为了防止高温熔融物溅落炸裂瓶底。不可张冠李戴。

## 自测参考
1. 形成液封，防止生成的氧气从长颈漏斗上口逸出，确保气体从导气管导出。
2. ①集气瓶未注满水，残留气泡；②导管口刚有气泡冒出就立即收集（此时排出的是装置内原有空气）；③收集完成后玻璃片未完全盖严或取出时操作过猛混入空气。
3. $\text{C} + \text{O}_2 \xrightarrow{\text{点燃}} \text{CO}_2$；向反应后的集气瓶中倒入少量澄清石灰水，振荡，若石灰水变浑浊，则证明生成了二氧化碳。
4. ×（二氧化锰也可作氯酸钾分解的催化剂；在高锰酸钾受热分解反应中它是生成物；在某些反应中甚至可作为反应物参与过程。）
