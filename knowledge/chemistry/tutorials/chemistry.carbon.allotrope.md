# 碳的单质

## 一句话记住
碳单质物理性质迥异，根本原因是碳原子排列方式不同；化学性质相似，因为组成元素均为碳。

## 核心概念
- **同素异形体**：由同种元素组成的不同单质。初中阶段重点掌握金刚石、石墨、C₆₀。它们互为同素异形体，属于单质而非混合物。
- **结构决定性质**：
  - 金刚石：碳原子呈正四面体空间网状排列 → 硬度最大、不导电 → 用于切割玻璃、钻探机钻头。
  - 石墨：碳原子呈层状排列，层间作用力弱 → 质软滑腻、能导电 → 用于铅笔芯、干电池电极、润滑剂。
  - C₆₀：形似足球的分子结构 → 在超导、材料科学、医药领域有广阔前景。
- **化学性质共性**：
  - 常温稳定：古代字画久不褪色。
  - 可燃性：$\text{C} + \text{O}_2 \xrightarrow{\text{点燃}} \text{CO}_2$（充分燃烧）；$2\text{C} + \text{O}_2 \xrightarrow{\text{点燃}} 2\text{CO}$（不充分燃烧）。
  - 还原性：$\text{C} + 2\text{CuO} \xrightarrow{\Delta} 2\text{Cu} + \text{CO}_2\uparrow$（实验室常用）；$3\text{C} + 2\text{Fe}_2\text{O}_3 \xrightarrow{\text{高温}} 4\text{Fe} + 3\text{CO}_2\uparrow$（工业炼铁原理之一）。
- **相互转化**：石墨在高温高压下转化为金刚石属于化学变化（生成了新物质，晶体结构改变）。

## 例题演示
【例题】（佛山顺德区模拟题改编）下列有关碳单质的说法错误的是（ ）
A．金刚石和石墨的物理性质差异很大，是因为碳原子排列方式不同
B．活性炭具有吸附性，可用于除去水中的色素和异味
C．石墨转化为金刚石属于物理变化
D．常温下碳的化学性质不活泼，因此古代字画能长久保存
【解析】逐项排查：A正确，结构决定性质是核心考点；B正确，活性炭疏松多孔，吸附属物理性质；C错误，石墨与金刚石是不同物质，结构改变伴随新物质生成，属化学变化；D正确，常温下碳原子最外层4个电子不易得失，化学性质稳定。本题选C。
【解题技巧】遇到“性质对比题”，先定位“结构差异”，再推导“物理性质”，最后匹配“用途”。化学性质一律按“碳单质共性”处理。

## 易错点
1. 概念混淆：将“木炭、活性炭、炭黑、焦炭”视为纯净物。实际它们主要成分是碳，但含少量杂质，属于混合物；而金刚石、石墨、C₆₀是纯净物中的单质。
2. 性质归类错误：导电性、硬度、颜色、状态属于物理性质；可燃性、还原性、常温稳定性属于化学性质。填空题务必准确归类。
3. 忽略“结构决定性质”的逻辑表述：简答题若只写“因为结构不同”可能扣分，需完整表述为“因碳原子排列方式不同，导致微观结构差异，进而引起物理性质不同”。
4. 方程式书写规范：高温还原金属氧化物时，条件常为“高温”或“$\Delta$”，生成CO₂必须标“↑”；漏写条件或气体符号是顺德中考高频失分点。

## 关联知识点

- `chemistry.basic.element`（元素与元素符号）：元素符号：一个字母全大写；两个字母「首大次小」。宏观表示一种元素，微观表示该元素的一个原子。

## 自测提示
1. 用“结构—性质—用途”逻辑链说明为何石墨可作润滑剂而金刚石不能。
2. 判断正误并简述理由：① 金刚石和石墨混合在一起形成的是混合物。② C₆₀中碳元素的化合价为+4价。③ 碳单质在空气中燃烧一定生成二氧化碳。
3. 写出碳还原氧化铜的实验现象，并说明试管口略向下倾斜的原因。

## 自测参考
1. 石墨为层状结构，层间作用力弱，受力易滑动，故质软滑腻可作润滑剂；金刚石为空间网状结构，硬度极大，无法滑动。
2. ①正确（两种不同单质混合）；②错误（C₆₀是单质，元素化合价为0）；③错误（氧气不足时生成CO）。
3. 现象：黑色粉末逐渐变红，澄清石灰水变浑浊；原因：防止冷凝水倒流炸裂试管底（实验前需预热，且药品通常含结晶水或潮湿）。
