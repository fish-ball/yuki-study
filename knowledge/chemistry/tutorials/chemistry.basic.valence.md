# 化合价与化学式

## 一句话记住

写化学式：正价在左、负价在右，交叉约简作下标，化合价代数和为 0。

## 核心概念

- **化合价**：表示原子相互化合的数目关系（预习先会用常见价，不必深究本质）。
- 常见价（先背）：H(+1)、O(-2)、Na(+1)、Mg(+2)、Al(+3)、Cl(-1)、S 在硫化物中常 -2、C 在化合物中常见 +4/-4（先关注氧化物与盐的基本式）。
- **化学式**：用元素符号表示物质组成。单质如 $O_2$、$Fe$；化合物如 $H_2O$、$CO_2$、$NaCl$。
- 书写步骤（化合物）：① 写出元素符号（正价左、负价右）；② 标明化合价；③ 交叉约简得下标；④ 检查正负化合价总数代数和是否为 0。

## 例题演示

**例 1** 写出氧化铝的化学式。

解：Al 为 +3，O 为 -2 → 交叉约简得 $Al_2O_3$。验证：$(+3)\times 2+(-2)\times 3=0$。

## 易错点

- 易错：下标直接抄化合价数字不约简（写成 $Al_3O_2$） → 正确：交叉后要约成最简整数比。
- 易错：把单质氧气写成 O → 正确：氧气分子是 $O_2$。

## 关联知识点

- `chemistry.basic.molecule`（分子原子离子）：分子保持物质化学性质；化学变化中分子可分、原子不可分。
- `chemistry.basic.change`（物理变化与化学变化）：有没有生成新物质：没有 → 物理变化；有 → 化学变化。
- `chemistry.basic.element`（元素与元素符号）：元素符号：一个字母全大写；两个字母「首大次小」。
