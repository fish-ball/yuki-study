# 元素与元素符号

## 一句话记住

元素符号：一个字母全大写；两个字母「首大次小」。

## 核心概念

- **元素**：具有相同核电荷数（质子数）的一类原子的总称（先记「种类」概念）。
- **元素符号**可表示：① 一种元素；② 该元素的一个原子。
- 书写规则：
  - 单字母：大写，如 H、C、O、N、S、P、K
  - 双字母：第一个大写、第二个小写，如 Cl、Mg、Al、Fe、Cu、Zn、Ca、Na、He
- 初学建议先熟记：H He C N O Na Mg Al Si P S Cl K Ca Fe Cu Zn

## 例题演示

**例 1** 下列书写正确的是：A. CA B. zn C. Mg D. AL

解：选 C。钙 Ca、锌 Zn、铝 Al，不能写成 CA / zn / AL。

## 易错点

- 易错：两个字母都大写（CA、AL、ZN） → 正确：第二字母必须小写。
- 易错：把化合物化学式当成元素符号 → 正确：元素符号只表示一种元素（如 O，不是 O₂）。

## 关联知识点

- `chemistry.basic.change`（物理变化与化学变化）：有没有生成新物质：没有 → 物理变化；有 → 化学变化。
- `chemistry.basic.molecule`（分子原子离子）：分子保持物质化学性质；化学变化中分子可分、原子不可分。
- `chemistry.basic.valence`（化合价与化学式）：写化学式：正价在左、负价在右，交叉约简作下标，化合价代数和为 0。
