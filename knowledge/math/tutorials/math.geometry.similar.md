# 相似三角形

## 一句话记住
形状相同、大小可变的三角形就是相似三角形，对应角相等、对应边成比例是解题的“金钥匙”。

## 核心概念
- **定义与记号**：两个三角形三个角分别相等，三条边对应成比例，则称这两个三角形相似，记作 $\triangle ABC \sim \triangle DEF$。
- **与全等的衔接**：全等是相似比为 $1$ 的特殊情况。暑假复习时，把全等判定中的“角边条件”平移过来即可理解相似判定。（注：全等强调“完全重合”，相似强调“形状一致”，证明思路高度同源。）
- **判定定理（中考必考）**：
  1. 两角分别相等（AA）：最基础、最高频，通常由平行线、公共角、对顶角或互余关系导出。**注意：只要有两个角对应相等，第三个角必然相等，无需再证。**
  2. 两边成比例且夹角相等（SAS）：务必核对“夹角”是否相等，非夹角不能判定。**口诀：见比例先找夹角，夹角不等不相似。**
  3. 三边成比例（SSS）：适用于已知三边长度或可通过计算得出三边的题目。需按从小到大（或从大到小）排序后比对。
- **重要性质**：设相似比为 $k$，则周长比 $= k$，面积比 $= k^2$；对应高、中线、角平分线之比均等于 $k$。
- **常见几何模型**：平行线截得的“A字型”“X字型”；直角三角形斜边上的高产生的“母子相似”（双垂直模型）；共角/共边结构需主动补画平行线或延长线构造相似。**关键技巧：复杂图形先“拆图”，将目标三角形单独圈出，忽略干扰线段。**

【补充说明·找相似的实操路径】针对部分同学觉得“无从下手”的情况，建议按以下顺序排查：
1. **先找角**：平行线同位角/内错角、公共角、对顶角、直角、互余/互补导出的等角。有2个等角直接定AA。
2. **再找边**：若角不够，看已知线段长度。将涉及的两个三角形的边分别按大小排序，检查是否成同一比例。
3. **最后验夹角**：若只有两组边成比例，必须确认这两组边的夹角相等，否则无法判定。
4. **定对应**：找到相等角所对的边即为对应边；成比例边的夹角即为对应角。**对应关系一旦确定，后续所有比例式、面积比、辅助线方向全部锁定。**

## 例题演示
【题目】如图，在 $\triangle ABC$ 中，$DE \parallel BC$，交 $AB$、$AC$ 于点 $D$、$E$。若 $AD=3$，$DB=2$，$AE=4.5$，求 $EC$ 的长及 $\triangle ADE$ 与 $\triangle ABC$ 的面积比。
【分析】由平行线直接得 AA 相似，利用对应边成比例列方程求线段，再结合面积比公式求解。
【解答】
$\because DE \parallel BC$，$\therefore \angle ADE = \angle B$，$\angle AED = \angle C$。
$\therefore \triangle ADE \sim \triangle ABC$（AA）。
由相似性质得 $\frac{AD}{AB} = \frac{AE}{AC}$。
$\because AB = AD + DB = 3 + 2 = 5$，
$\therefore \frac{3}{5} = \frac{4.5}{AC} \Rightarrow AC = 7.5$。
$\therefore EC = AC - AE = 7.5 - 4.5 = 3$。
相似比 $k = \frac{AD}{AB} = \frac{3}{5}$，
$\therefore S_{\triangle ADE} : S_{\triangle ABC} = k^2 = \left(\frac{3}{5}\right)^2 = \frac{9}{25}$。
【点拨】顺德中考常考“平行+比例”综合题，先证相似定比值，再用比值算线段或面积，步骤不可颠倒。书写时注意对应顶点顺序一致。

**【补充例题·模型突破】**（针对练习中标记“不会”的同学重点研读）
【题目】如图，在 $\triangle ABC$ 和 $\triangle ADE$ 中，$\angle BAC = \angle DAE = 90^\circ$，$AB=6$，$AC=8$，$AD=3$，$AE=4$。求证：$\triangle ABD \sim \triangle ACE$，并求 $BD:CE$ 的值。
【分析】本题无平行线，属于“共角型”相似。需先利用已知直角拆分出相等的夹角，再验证夹这个角的两边是否成比例。
【解答】
$\because \angle BAC = \angle DAE = 90^\circ$，
$\therefore \angle BAC - \angle DAC = \angle DAE - \angle DAC$，即 $\angle BAD = \angle CAE$。
又 $\because \frac{AB}{AC} = \frac{6}{8} = \frac{3}{4}$，$\frac{AD}{AE} = \frac{3}{4}$，
$\therefore \frac{AB}{AC} = \frac{AD}{AE}$。
$\therefore \triangle ABD \sim \triangle ACE$（SAS）。
$\therefore BD:CE = AB:AC = 3:4$。
【点拨】遇到“共顶点+等角”结构，优先尝试 SAS。若两边不成比例，再回头检查是否有隐藏的角度关系（如互余、同弧所对角等）。此类题型在顺德模拟考中极高频，掌握“拆角找夹角→验比例→得结论”三步法即可稳拿分。

**【新增例题·旋转/缩放下的对应关系】**（解决“图形摆放不同就卡壳”的问题）
【题目】已知 $\triangle ABC \sim \triangle ADE$，且 $\angle BAC = \angle DAE$。连接 $BD$、$CE$。若 $AB=4$，$AC=6$，$AD=2$，$AE=3$，求 $BD:CE$ 的值。
【分析】本题属于典型的“共顶点+相似”衍生模型。原相似关系提供边长比例，等角关系提供夹角，两者结合可构造出新的一对相似三角形。
【解答】
$\because \triangle ABC \sim \triangle ADE$，$\therefore \frac{AB}{AD} = \frac{AC}{AE} = 2$，且 $\angle BAC = \angle DAE$。
$\therefore \angle BAC - \angle DAC = \angle DAE - \angle DAC$，即 $\angle BAD = \angle CAE$。
在 $\triangle ABD$ 和 $\triangle ACE$ 中，$\frac{AB}{AC} = \frac{4}{6} = \frac{2}{3}$，$\frac{AD}{AE} = \frac{2}{3}$，且夹角 $\angle BAD = \angle CAE$。
$\therefore \triangle ABD \sim \triangle ACE$（SAS）。
$\therefore BD:CE = AB:AC = 2:3$。
【点拨】旋转或缩放后，原相似三角形的“腰”会重新组合成新的一对相似三角形。牢记：**原相似比决定新相似比，公共角/等角做桥梁**。考试时不要怕图形转了，先把已知相等的角标出来，对应边自然浮现。

【针对“不会”同学的思维脚手架】
很多同学卡壳是因为不知道“从哪里开始写证明”。请记住标准答题模板：
① 写出导角的依据（如：$\because \angle 1 = \angle 2$，$\angle 3 = \angle 4$）；
② 得出相似结论（$\therefore \triangle X \sim \triangle Y$）；
③ 列出比例式（$\therefore \frac{a}{b} = \frac{c}{d}$）；
④ 代入数据计算或转化面积/周长。
考试时即使最终结果没算出来，写出前两步也能拿到过程分。

## 易错点
- **字母顺序错位**：相似符号 $\sim$ 前后顶点必须严格对应，如 $\triangle ABC \sim \triangle DEF$ 表示 $A\leftrightarrow D$。顺序写反会导致比例式全部错误。**建议：证明前先口头或草稿纸上对齐对应顶点，再落笔写符号。**
- **SAS 判定漏看夹角**：给出两边成比例时，必须确认这两边的夹角相等。若相等的是其中一边的对角，属于“边边角”陷阱，无法判定相似。
- **面积比与相似比混淆**：牢记“面积比等于相似比的平方”。题目若给的是周长比或中线比，需先转化为相似比再平方，切忌直接套用。
- **比例式变形失误**：$\frac{a}{b}=\frac{c}{d}$ 交叉相乘得 $ad=bc$ 时，默认线段长度为正数；初中阶段不涉及负值，但需注意单位统一后再列比例。
- **图形变换后的对应关系混乱**：近年佛山/顺德考题常出现三角形旋转、翻折后的相似问题。此时原图的“上下左右”方位已变，**切勿凭直觉找对应边**，必须通过角度相等或边长比例重新推导对应关系。

【补充易错提醒】
- **盲目套用模型**：看到“A字”“8字”“K字”就默认相似，但忽略了图形是否真的满足角度或比例条件。必须养成“先证后算”的习惯，没有判定依据不能直接写比例。
- **忽略隐含条件**：如“等腰三角形底角相等”“正方形四边相等且四个角为直角”“切线垂直半径”等，这些往往是导出第一组等角或等边的关键，读题时需圈画出来。
- **误以为必须有平行线**：很多学生认为相似只能由平行线产生。实际上，公共角、对顶角、圆周角、旋转角、甚至代数计算得出的等角都能作为AA判定的依据。遇到无平行线的题，第一时间扫描“共顶点”和“特殊角”。

## 关联知识点
- `math.geometry.congruent`（全等三角形）：学习本点时可对照复习。
- `math.geometry.circle.angle`（圆周角与圆心角）：同弧所对的圆周角等于它所对圆心角的一半；同弧或等弧所对的圆周角相等。
- `math.integrated.geometry_hard`（几何压轴）：几何压轴不考偏题怪题，考的是“模型识别+条件转化+分类讨论”。抓住相似与切线两大主线，辅助线就是破题的钥匙。

## 自测提示
- 默写三种判定定理的条件，并尝试用尺规画出满足 SAS 判定的两个相似三角形草图。
- 找一道顺德近五年中考真题中的“一线三等角”或“双垂直”模型，标出所有相等的角，验证是否满足 AA 或 SAS。
- 思考：若两个相似三角形的面积比为 $4:9$，它们的周长比是多少？对应中线比呢？
- **新增实操**：拿一张透明纸描下课本中的“A字型”和“X字型”，旋转或翻转透明纸，观察对应顶点如何变化，强化“形状相同与位置无关”的空间观念，避免考试时因图形摆放不同而卡壳。
- **定向挑战**：独立绘制一个“旋转相似”草图（如共顶点等腰三角形），尝试证明由它们“腰”组成的两个新三角形相似，并写出完整证明过程。

【定向巩固建议】针对本场标记“不会”的同学：请独立完成一道含“共顶点+等角”的变式题，重点练习“拆角→列比例→写结论”的书写规范。完成后对照答案，检查是否每一步都有判定依据，杜绝跳步。

## 自测参考
- 判定定理默写以教材为准。SAS 作图提示：先画夹角，再在两边上截取成比例的线段，连接端点即可。
- 模型验证提示：一线三等角需抓住“平角减公共角得等角”；双垂直模型必含两个直角加一个公共锐角，直接得 AA。
- 面积比 $4:9 \Rightarrow$ 相似比 $2:3 \Rightarrow$ 周长比 $2:3$，对应中线比、高之比、角平分线比均等于相似比 $2:3$。
- 补充例题答案：证明过程如上，$BD:CE = 3:4$。建议将此类“共角+SAS”题型整理入错题本，下次遇到同类结构可直接调用判定路径。
- 定向挑战参考：设 $\triangle ABC$ 与 $\triangle ADE$ 均为等腰三角形且顶角相等，则 $\angle BAC = \angle DAE \Rightarrow \angle BAD = \angle CAE$，且 $AB/AC = AD/AE$，故 $\triangle ABD \sim \triangle ACE$。此即“手拉手”模型的核心逻辑，熟练掌握后可秒杀多道压轴小题。
