# 二次函数图像与性质

## 一句话记住
二次函数图像是一条抛物线，开口方向看 $a$ 的正负，对称轴与顶点由 $a,b,c$ 共同决定，掌握“配方法”或“公式法”即可快速锁定图像特征。

## 核心概念
- **一般式**：$y = ax^2 + bx + c$（$a \neq 0$），图像为抛物线。其中 $c$ 直接决定抛物线与 $y$ 轴的交点位置 $(0,c)$。
- **开口方向**：$a > 0$ 开口向上，有最小值；$a < 0$ 开口向下，有最大值。口诀：“正上负下”。
- **对称轴**：直线 $x = -\frac{b}{2a}$。注意公式自带负号，可辅助记忆为“负二分之b/a”。结合 $a,b$ 符号可快速判断对称轴位置：**“左同右异”**（即 $a,b$ 同号时对称轴在 $y$ 轴左侧，异号时在右侧）。
- **顶点坐标**：$\left(-\frac{b}{2a}, \frac{4ac-b^2}{4a}\right)$。推荐优先配成顶点式 $y = a(x-h)^2 + k$，直接读出顶点 $(h,k)$，避免硬套公式导致计算失误。
- **增减性**：以对称轴为分界线，必须结合开口方向判断。$a>0$ 时，对称轴左侧 $y$ 随 $x$ 增大而减小，右侧增大；$a<0$ 时相反。答题时务必明确写出“在……范围内”，不可省略区间限定。
- **与坐标轴交点**：令 $x=0$ 得 $y$ 轴交点 $(0,c)$；令 $y=0$ 解一元二次方程，$\Delta = b^2-4ac$ 决定与 $x$ 轴交点个数（$\Delta>0$ 两个，$\Delta=0$ 一个即相切，$\Delta<0$ 无交点）。几何意义上，$\Delta$ 反映抛物线与 $x$ 轴相交的“穿透程度”。
💡 **作图与识图基础**：遇到陌生解析式，先求顶点与对称轴定位“骨架”，再算与坐标轴交点填充“血肉”，最后根据开口方向连线。这是解决所有图像问题的第一步，也是突破“不会”状态的关键起手式。

🔹 **补充说明（针对“不会”同学的拆解）**：很多同学在看到题目时觉得“不会”，往往是因为不知道从哪下手。请记住这个固定流程：**一看 $a$（定开口），二算轴（找对称轴），三求顶（定最值），四判交（看 $\Delta$ 和截距）**。按顺序填空，就能把抽象的“不会”转化为具体的步骤。佛山中考常在此流程基础上叠加“系数符号判断”或“平移变换”，熟练此流程是拿稳基础分的前提。

## 例题演示
**例1**：已知二次函数 $y = -2x^2 + 4x + 1$，求开口方向、对称轴、顶点坐标及最值。
**解**：
1. $a = -2 < 0$，故开口向下，函数存在最大值。
2. 对称轴：$x = -\frac{b}{2a} = -\frac{4}{2 \times (-2)} = 1$。
3. 顶点横坐标为 $1$，代入原式求纵坐标：$y = -2(1)^2 + 4(1) + 1 = 3$，顶点为 $(1, 3)$。
4. 最大值为 $3$。当 $x < 1$ 时 $y$ 随 $x$ 增大而增大；当 $x > 1$ 时 $y$ 随 $x$ 增大而减小。
💡 **教师点拨**：求顶点纵坐标时，代入横坐标计算通常比硬套 $\frac{4ac-b^2}{4a}$ 更快且不易算错，建议养成习惯。

🛠️ **破题指引**：此题为“送分题”型。拿到题先圈出 $a=-2, b=4, c=1$，直接套用口诀和公式。若考试时大脑空白，默念“正上负下、负二分之b/a”，答案自然浮现。

**例2**：将 $y = x^2 - 6x + 5$ 化为顶点式，并说明由 $y=x^2$ 如何平移得到。
**解**：
配方：$y = (x^2 - 6x + 9) - 9 + 5 = (x-3)^2 - 4$。
顶点式为 $y = (x-3)^2 - 4$，顶点 $(3, -4)$。
平移规律：由 $y=x^2$ 的图像向右平移 $3$ 个单位，再向下平移 $4$ 个单位得到。
💡 **教师点拨**：平移口诀“左加右减（对 $x$），上加下减（对常数项）”。先左右后上下，顺序不影响最终结果，但切忌对 $a$ 或 $x^2$ 直接加减。

🛠️ **破题指引**：配方是必考基本功。卡壳时回想完全平方公式 $(x \pm m)^2 = x^2 \pm 2mx + m^2$。一次项系数是 $-6$，一半是 $-3$，平方是 $9$，补 $9$ 再减 $9$ 保持平衡。平移看括号内 $x$ 的变化和末尾常数变化。

**例3**（针对高频失分点补充）：已知二次函数 $y = (m-2)x^2 + 4x + 1$ 的图像开口向下，且与 $x$ 轴有两个不同的交点，求 $m$ 的取值范围。
**解**：
1. **二次函数前提**：二次项系数不为0，即 $m-2 \neq 0 \Rightarrow m \neq 2$。
2. **开口向下**：$a = m-2 < 0 \Rightarrow m < 2$。
3. **与 $x$ 轴有两个不同交点**：$\Delta > 0$。
   $\Delta = 4^2 - 4(m-2)(1) = 16 - 4m + 8 = 24 - 4m > 0 \Rightarrow 4m < 24 \Rightarrow m < 6$。
4. **综合条件**：取交集得 $m < 2$。（注：此处 $m<2$ 已自动满足 $m<6$ 和 $m\neq2$）
💡 **教师点拨**：含参二次函数题必查两点：① $a \neq 0$；② $\Delta$ 的条件。切勿漏掉隐含限制，这是顺德及佛山中考选择题和填空题的常见陷阱。

🛠️ **破题指引**：题干出现“二次函数”四个字，第一反应必须是“二次项系数 $\neq 0$”。很多同学“不会”就是因为漏了这一步导致扣分。列不等式组时，务必画数轴取公共部分，不要凭感觉写答案。

**例4**（补充：利用对称性比较函数值大小）：已知二次函数 $y = x^2 - 4x + 3$ 图象上有三点 $A(-1, y_1)$，$B(2, y_2)$，$C(5, y_3)$，比较 $y_1, y_2, y_3$ 的大小。
**解**：
1. 确定对称轴：$x = -\frac{-4}{2\times1} = 2$。
2. 判断开口：$a=1>0$，开口向上，离对称轴越远的点，函数值越大。
3. 计算各点横坐标到对称轴的距离：
   $A$ 点距离：$|-1 - 2| = 3$
   $B$ 点距离：$|2 - 2| = 0$ （恰在对称轴上，为最小值）
   $C$ 点距离：$|5 - 2| = 3$
4. 比较：$B$ 最近，$A,C$ 等距。故 $y_2 < y_1 = y_3$。
💡 **教师点拨**：佛山中考极爱考“不代入计算直接比大小”。核心逻辑是“开口定趋势，距离定大小”。若开口向上，距离对称轴越远值越大；开口向下则反之。此法可秒杀选择题，大幅节省考试时间！

🛠️ **破题指引**：遇到“比大小”题，严禁盲目代入求值（浪费时间且易错）。标准动作：①求对称轴；②看开口；③算水平距离。距离就是绝对值 $|x_i - h|$。掌握此法，同类题正确率可达100%。

**例5**（新增：佛山中考高频·由图象判断系数符号）：如图（文字描述），二次函数 $y=ax^2+bx+c$ 的图象开口向下，对称轴在 $y$ 轴右侧，且与 $y$ 轴交于正半轴，顶点在第一象限。判断下列各式的符号：① $abc$；② $2a+b$；③ $a-b+c$；④ $4a+2b+c$。
**解**：
1. 开口向下 $\Rightarrow a<0$；与 $y$ 轴交于正半轴 $\Rightarrow c>0$。
2. 对称轴 $x=-\frac{b}{2a}>0$，因 $a<0$，故 $-\frac{b}{2a}>0 \Rightarrow b>0$（或直接记“左同右异”，对称轴在右，$a,b$ 异号，得 $b>0$）。
   ① $abc$：$(-)\times(+)\times(+) < 0$，符号为负。
3. 对称轴 $x=-\frac{b}{2a}<1$（观察图象可知对称轴在 $x=1$ 左侧），两边乘 $2a$（注意 $a<0$ 不等号变向）：$-b > 2a \Rightarrow 2a+b < 0$。
   ② $2a+b$ 符号为负。
4. ③ $a-b+c$：即 $x=-1$ 时的函数值。观察图象，$x=-1$ 对应点在 $x$ 轴下方，故 $y<0$，符号为负。
5. ④ $4a+2b+c$：即 $x=2$ 时的函数值。观察图象，$x=2$ 对应点在 $x$ 轴上方，故 $y>0$，符号为正。
💡 **教师点拨**：此类题是顺德一模、二模及佛山中考选择压轴的常客。核心技巧是“特殊值法”：$x=1$ 看 $a+b+c$，$x=-1$ 看 $a-b+c$，$x=2$ 看 $4a+2b+c$，$x=-2$ 看 $4a-2b+c$。结合图象上下方直接读正负，无需复杂计算。

🛠️ **破题指引**：看到图象题，先标 $a,b,c,\Delta$ 的已知符号，再找特殊点横坐标对应的函数值位置。涉及 $2a+b$ 或 $2a-b$ 时，一律转化为对称轴 $x=-\frac{b}{2a}$ 与特定数值（如 $1$ 或 $-1$）的大小比较，注意乘除负数时不等号方向。

## 易错点
- **对称轴公式漏负号**：常误写成 $x = \frac{b}{2a}$。牢记公式自带负号，或记作“负二分之b/a”。
- **顶点纵坐标硬套公式出错**：$\frac{4ac-b^2}{4a}$ 分子易符号颠倒。建议优先用配方法，或求出 $x=h$ 后代入原解析式求 $y$，双重保险。
- **增减性脱离区间表述**：增减性必须限定在对称轴的一侧。只说“$y$ 随 $x$ 增大而增大”是错的，必须写“当 $x > -\frac{b}{2a}$ 时…”。
- **参数题忽略前提**：如题干说“二次函数”，则二次项系数绝对不为0（如 $y=(m-1)x^2+2x$ 中 $m \neq 1$）；若只说“函数”，则可能退化为一次函数，需分类讨论。
- **平移口诀混淆**：“左加右减”作用于括号内的 $x$ 本身（即 $x \to x+m$），“上加下减”作用于整个函数末尾的常数 $k$。顺序可互换，但切忌对 $a$ 或 $x^2$ 直接加减。
- **忽视 $\Delta$ 与 $a$ 的联立**：求参数范围时，$\Delta > 0$ 只是必要条件之一，必须同时考虑 $a \neq 0$ 及题目其他限制（如开口方向、过定点等），最后务必取交集。
- **新增：图象读图陷阱**：题目给出草图时，勿盲目相信比例。一切以解析式或明确标注的数据为准。特别注意 $x=1$ 或 $x=-1$ 时的函数值符号（即 $a+b+c$ 与 $a-b+c$ 的正负），这是压轴题常用突破口。
- **新增：比较函数值大小误区**：不要死算三个 $y$ 值。先找对称轴，再看开口方向，最后比横坐标到对称轴的水平距离，效率提升一倍且准确率更高。
- **新增：对称轴位置判断失误**：未掌握“左同右异”规律，导致 $b$ 的符号判断错误，进而牵连 $2a+b$ 等代数式符号判断全错。做题时务必先定 $a$，再推 $b$。
- **新增：网格/整数点遗漏**：佛山中考偶有结合平面直角坐标系的网格题，要求找出图象经过的整数点或利用格点构造抛物线。此时需回归定义，验证 $x$ 为整数时 $y$ 是否为整数，勿仅凭视觉估算。
📝 **顺德教师实战提醒**：考场遇到“不会”的题，先检查是否漏了“$a \neq 0$”或“$\Delta$ 条件”。这两处占含参题失分的70%以上。养成“动笔前先圈条件”的习惯，能避开绝大多数低级错误。对于图象判断题，务必在草稿纸上画出简易坐标系，标出关键点位置，避免眼高手低。

## 关联知识点

- `math.function.quadratic.formula`（二次函数解析式）：学习本点时可对照复习。
- `math.function.linear`（一次函数）：一次函数是形如 $y=kx+b$（$k,b$ 为常数，$k
eq0$）的函数，图像是一条直线，$k$ 控制倾斜方向与陡缓，$b$ 控制与 $y$ 轴交点位置。

## 自测参考
1. 对称轴 $x=2$；顶点 $(2, -5)$；开口向上。
2. $\Delta = 2^2 - 4m(-1) = 4 + 4m > 0$ 且 $m \neq 0$，解得 $m > -1$ 且 $m \neq 0$。
3. 错误。对称轴 $x=2$，$a=-1<0$，右侧应单调递减。
4. $y = 2(x+1)^2 - 3$。
5. 对称轴 $x=1$，开口向下。距离对称轴：$P_2$ 为0，$P_1$ 为3，$P_3$ 为3。故 $y_b < y_a = y_c$。
6. 开口向下 $\Rightarrow a<0$；对称轴 $x=-\frac{b}{2a}=1>0 \Rightarrow b>0$；交 $y$ 轴正半轴 $\Rightarrow c>0$。故 $abc<0$。$x=-1$ 时图象在 $x$ 轴下方 $\Rightarrow a-b+c<0$。由对称轴 $b=-2a$，代入 $x=1$ 处顶点纵坐标或观察 $x=3$ 时 $y=9a+3b+c=9a-6a+c=3a+c$，因对称轴为 $x=1$，$x=3$ 与 $x=-1$ 对称，函数值相等且小于0，故 $3a+c<0$。
