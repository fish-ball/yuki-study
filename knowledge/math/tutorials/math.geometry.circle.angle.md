# 圆周角与圆心角

针对部分同学在练习中标记“不会”的情况，本教程在保留原核心框架的基础上，强化了“识图三步法”与典型模型的拆解步骤。请准备草稿纸，边看边画弧，切勿只看不动笔。顺德中考几何题重基础、重规范，吃透本节即可稳拿基础分。

## 一句话记住
同弧所对的圆周角等于它所对圆心角的一半；同弧或等弧所对的圆周角相等。

## 核心概念
- **圆心角**：顶点在圆心，两边与圆相交的角。记作 $\angle AOB$（$O$ 为圆心）。其度数等于它所对弧的度数。
- **圆周角**：顶点在圆上，两边都与圆相交的角。记作 $\angle ACB$（$C$ 在圆上）。
- **定理**：在同圆或等圆中，同弧或等弧所对的圆周角相等，且都等于这条弧所对的圆心角的一半。即若 $\overset{\frown}{AB}$ 所对圆心角为 $\alpha$，圆周角为 $\beta$，则 $\beta = \frac{1}{2}\alpha$。
- **重要推论**：
  1. 直径所对的圆周角是直角（$90^\circ$）；$90^\circ$ 的圆周角所对的弦是直径。
  2. 圆内接四边形对角互补。
- **顺德中考提示**：该知识点常以选择题、填空题形式考查直接计算，或与三角形、四边形结合出现在解答题第一问，属高频基础送分题。暑假需熟练建立“找弧→定角→套公式”的思维路径。**关键提醒**：圆周角的大小只与它所对的弧有关，与顶点在圆上的具体位置无关（只要在同侧）。遇到复杂图形，先用铅笔描出对应的弧，能瞬间理清关系。若题目只给圆周角求半径或弦长，优先考虑“连接圆心与弦端点构造等腰/等边三角形”。

> **【补充说明｜针对标记“不会”的同学】**
> 很多同学在第一步“找弧”时就卡住。请记住：**角的内部就是它所对的弧**。画一个角时，用荧光笔把角的两条边夹住的那段圆弧涂出来，这段弧就是“基准”。圆心角和圆周角必须对着**完全相同的一段弧**才能套用倍数关系。如果弧不同，必须先通过“等弧代换”或“圆内接四边形”转化后再计算。

## 例题演示
**例1**（基础计算）如图，在 $\odot O$ 中，$\overset{\frown}{AB}$ 所对的圆心角 $\angle AOB = 100^\circ$，点 $C$ 在优弧 $AB$ 上，求 $\angle ACB$ 的度数。
**解**：由圆周角定理，同弧所对圆周角等于圆心角的一半，得
$$\angle ACB = \frac{1}{2} \angle AOB = \frac{1}{2} \times 100^\circ = 50^\circ$$
答：$\angle ACB = 50^\circ$。
> **【思路拆解】** 看到圆心角 $100^\circ$ → 锁定 $\overset{\frown}{AB}$ → 找同弧上的圆周角 $\angle ACB$ → 直接除以2。这是最直接的套公式题型，务必形成肌肉记忆。

**例2**（综合应用）如图，$AB$ 是 $\odot O$ 的直径，点 $C$ 在圆上，$\angle BAC = 35^\circ$，求 $\angle ABC$ 及 $\overset{\frown}{BC}$ 所对圆心角 $\angle BOC$ 的度数。
**解**：
- 因为 $AB$ 是直径，所以 $\angle ACB = 90^\circ$（直径所对圆周角为直角）。
- 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle ABC = 90^\circ - \angle BAC = 90^\circ - 35^\circ = 55^\circ$。
- $\overset{\frown}{BC}$ 所对圆周角为 $\angle BAC = 35^\circ$，故其所对圆心角 $\angle BOC = 2 \times 35^\circ = 70^\circ$。
答：$\angle ABC = 55^\circ$，$\angle BOC = 70^\circ$。
> **【思路拆解】** 题干出现“直径”二字，条件反射写 $90^\circ$。求另一角用互余，求圆心角先找它对的圆周角（$\angle BAC$ 对 $\overset{\frown}{BC}$），再乘2。注意区分哪个角对哪段弧。

**例3**（模型应用·突破“不会”瓶颈）如图，$A, B, C, D$ 四点在 $\odot O$ 上，$AC$ 与 $BD$ 交于点 $E$。若 $\angle ABD = 50^\circ$，$\angle BDC = 30^\circ$，求 $\angle BEC$ 的度数。
**解**：
- **找弧**：观察 $\angle ACD$ 与 $\angle ABD$，它们都对着弧 $\overset{\frown}{AD}$。
- **定角**：根据“同弧所对圆周角相等”，得 $\angle ACD = \angle ABD = 50^\circ$。
- **套公式/用外角**：在 $\triangle CDE$ 中，$\angle BEC$ 是外角，故 $\angle BEC = \angle ACD + \angle BDC = 50^\circ + 30^\circ = 80^\circ$。
答：$\angle BEC = 80^\circ$。
> **【思路拆解】** 此题为经典“8字模型”。难点在于已知角不在目标三角形内。技巧：利用“同弧等角”把 $\angle ABD$ 转移到 $\angle ACD$，使两个已知角集中到 $\triangle CDE$ 中，再用三角形外角性质求解。画图时建议将 $\overset{\frown}{AD}$ 标红，一眼看出等角关系。

**例4**（辅助线突破·构造圆心角）如图，在 $\odot O$ 中，弦 $AB$ 的长为 $6\text{cm}$，$\angle ACB = 30^\circ$（点 $C$ 在优弧上），求 $\odot O$ 的半径。
**解**：
- **分析**：已知圆周角求半径，通常需连接圆心与弦的端点，将圆周角转化为圆心角，再利用三角形性质求解。
- **作辅助线**：连接 $OA, OB$。
- **定关系**：由圆周角定理，$\angle AOB = 2\angle ACB = 2 \times 30^\circ = 60^\circ$。
- **算结果**：$\because OA=OB$（半径相等），且 $\angle AOB=60^\circ$，$\therefore \triangle AOB$ 为等边三角形。故半径 $OA = AB = 6\text{cm}$。
答：$\odot O$ 的半径为 $6\text{cm}$。
> **【思路拆解】** “知角求半径”必连圆心。$30^\circ$ 圆周角对应 $60^\circ$ 圆心角，配合两半径相等，直接锁定等边三角形。此类“$30^\circ$ 对半径”、“$45^\circ$ 对 $\sqrt{2}$ 倍半径”、“$60^\circ$ 对等边”是顺德中考高频数值组合，建议整理成口诀背诵。

**例5**（综合突破·“8字模型”与相似铺垫）如图，弦 $AC$、$BD$ 交于点 $E$，连接 $AB$、$CD$。若 $\angle ABD = 45^\circ$，$\angle BDC = 35^\circ$，求 $\angle AEB$ 的度数，并说明 $\triangle ABE$ 与 $\triangle DCE$ 的关系。
**解**：
- **找弧定角**：$\angle ACD$ 与 $\angle ABD$ 均对弧 $\overset{\frown}{AD}$，故 $\angle ACD = \angle ABD = 45^\circ$。
- **外角计算**：在 $\triangle CDE$ 中，$\angle AEB$ 为外角，$\angle AEB = \angle ACD + \angle BDC = 45^\circ + 35^\circ = 80^\circ$。
- **相似判定**：同理可证 $\angle BAC = \angle BDC$，结合对顶角相等，可得 $\triangle ABE \sim \triangle DCE$。此模型是后续学习相似三角形的核心图形之一，务必熟练掌握。
答：$\angle AEB = 80^\circ$，$\triangle ABE \sim \triangle DCE$。
> **【思路拆解】** 本题在例3基础上增加了相似判断。记住结论：圆内两条弦相交形成的上下两个三角形一定相似（AA判定）。掌握此结论可直接用于后续面积比、线段比例的计算，避免重复证明。

## 易错点
1. **忽略“同弧/等弧”前提**：不同弧所对的圆周角与圆心角无直接倍数关系，解题前务必确认是否对应同一段弧。建议用荧光笔标出角的两边所夹的弧，做到“一眼定位”。
2. **混淆优弧与劣弧（补角陷阱）**：若点在劣弧上，所对圆周角与优弧上的圆周角互补（和为 $180^\circ$），而非相等。“同弧所对圆周角相等”仅适用于**同侧**顶点。画图时务必标清点的位置！
   > **【补充纠正】** 很多同学看到圆就默认“相等”，忽略了点可能在弦的另一侧。判断方法：过弦两端点连线，看顶点是否在弦的同侧。异侧则用“圆内接四边形对角互补”或“$180^\circ$ 减去同侧圆周角”计算。
3. **漏看隐含条件**：如未识别出“直径”导致无法使用 $90^\circ$ 推论；或未注意点在圆上的位置（优弧/劣弧侧）导致角度计算错误。看到圆就下意识找直径和半径。
4. **书写不规范**：几何步骤中需明确写出“∵ $\angle ACB$ 与 $\angle AOB$ 对同弧 $\overset{\frown}{AB}$，∴ $\angle ACB = \frac{1}{2}\angle AOB$”，避免跳步扣分。顺德中考阅卷对定理依据要求严格，写清“同弧所对”四字可保平安。
5. **度数概念混淆**：圆心角的度数等于所对弧的度数，但圆周角的度数等于所对弧度数的一半。切勿将弧的度数直接当作角度代入计算，单位要统一。
6. **顶点位置误判**：圆周角顶点必须在圆上，且两边必须都与圆相交。若顶点在圆内（如两条弦交点）或圆外（如切线与割线夹角），均不属于圆周角，不可直接套用本定理。遇到非标准图形，先判断顶点位置再选定理。
   > **【补充说明】** 初三阶段暂不深入圆外角/圆内角公式，但若题目图形复杂，先问自己：“顶点到底在哪？”若在圆内/外，优先寻找包含该点的三角形，利用外角或内角和间接求解，不要强行套定理。

## 关联知识点
- `math.geometry.circle`（圆的基本性质）：学习本点时可对照复习，重点回顾半径、弦、弧的关系及垂径定理。圆中“知一求二”的思想在本节同样适用。
- `math.geometry.similar`（相似三角形）：圆中常出现“一线三等角”或“共角共边”结构，结合圆周角相等极易导出相似三角形。例如圆内接四边形被对角线分割后，上下两个三角形往往相似，面积比等于相似比的平方，此考点在顺德中考解答题第二问中频繁联动。掌握本节可为后续相似章节打下坚实基础。

## 自测提示
1. 判断正误：圆周角的顶点一定在圆上，且两边必须都与圆相交。（ ）
2. 填空：若某弧所对圆周角为 $40^\circ$，则该弧所对圆心角为______$^\circ$；若圆心角为 $n^\circ$，则圆周角为______$^\circ$。
3. 简算：已知 $\odot O$ 中，弦 $CD$ 为直径，点 $A$ 在圆上，$\angle AOD = 60^\circ$，求 $\angle ACD$ 的度数。（提示：注意观察 $\angle ACD$ 对应哪段弧）
4. 拓展思考：若例1中点 $C$ 移动到劣弧 $AB$ 上，$\angle ACB$ 的度数会变为多少？为什么？

## 自测参考
1. √。完全符合圆周角定义。
2. $80$；$\frac{n}{2}$。直接套用定理即可。
3. $30^\circ$。$\angle ACD$ 与 $\angle AOD$ 均对应弧 $\overset{\frown}{AD}$，由定理得 $\angle ACD = \frac{1}{2} \angle AOD = \frac{1}{2} \times 60^\circ = 30^\circ$。暑假练习建议配合草稿图标注对应弧，可大幅降低失误率。
4. $130^\circ$。此时 $C$ 位于劣弧上，所对的是优弧 $AB$（度数为 $360^\circ - 100^\circ = 260^\circ$），故圆周角为 $260^\circ \div 2 = 130^\circ$。核心规律：**同弧同侧相等，异侧互补**（$50^\circ + 130^\circ = 180^\circ$）。掌握此规律可秒杀此类动点变式题。
